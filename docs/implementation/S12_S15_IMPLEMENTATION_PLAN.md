## 5. How golden tests keep Fable on course

1. **Just in time, in batches.** Claude drafts golden files from the gate text a batch at a
   time, so each batch reflects what earlier milestones built:
   B1 = M1–M4, B2 = M5–M9 (including M8a), B3 = M10–M14, B4 = M15–M18, B5 = M19–M21.
2. **Red first.** Before Fable starts milestone *n*, the owner script runs its golden tests
   on the current code: they must **fail** (or error on missing symbols). A golden test that
   already passes is rejected and rewritten.
3. **Sabotage after.** For each milestone Claude supplies 2–4 small sabotage patches (e.g.
   "skip the fence check", "count expired leases", "release LOCKED on timeout"). The owner
   verify script applies each in a throw-away worktree; its golden test must fail with an
   assertion.
4. **Invariant checker grows.** `assert_system_invariants(db)` starts in M2 with I5 and

## 6. The autonomous loop, progress and checkpoints

`S12_AUTOPILOT.md` (delivered with batch B1) follows the S0–S11 AUTOPILOT v2 pattern:

- **Session start:** re-read the gate sections on the current milestone card, the last 15
  log lines, `git status`; resume. The repository, not memory, is the state.
- **Loop inside a milestone:** run the milestone certifier → take the first failing check →
  fix `src\` → full suite green (S0–S11 included) → commit `s12: Mxx <check> <what>` → log
  line → repeat. No message to the owner between iterations.
- **Milestone end:** cross-check (all earlier golden suites, concurrency ×5, scope =
  `src\`, `tests\agent\`, allowed `docs\gates\` files only), log `MILESTONE Mxx REACHED`,
  continue to the next milestone unless it is ★.
- **STOP conditions:** gate §19.1 (including a golden test that contradicts the gate); the
  same check failing after 3 iterations; a PASS turning FAIL not restored in one
  iteration; any need to touch S0–S11 code (§19.3).

`S12_PROGRESS.md` is regenerated by the owner checkpoint script from the certifier output:
one row per milestone with golden pass counts, concurrency-run count, sabotage result,
invariants active, and the commit. Fable's log is evidence; the progress file is truth.

| Checkpoint | When | Owner time |
|---|---|---|
| ⚙ automatic | every milestone end (script) | ~1 min |
| ★ review | M0, M1, M8a, M14, M21 | 10–20 min each |
| STOP | whenever Fable stops | forward to Claude, paste ruling back |
